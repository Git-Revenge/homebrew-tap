# Git Revenge Homebrew tap

Install [Git Revenge](https://gitrevenge.com/) on macOS:

```sh
brew install --cask git-revenge/tap/gitrevenge
```

Update with `brew upgrade --cask gitrevenge`.

The cask follows the latest stable release of
[Git-Revenge/GitRevenge](https://github.com/Git-Revenge/GitRevenge/releases). Release
candidates are not published here. The `Bump cask` workflow checks for a new release every
six hours and updates `Casks/gitrevenge.rb` itself.
